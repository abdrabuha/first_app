1) ما هو Git و GitHub و VS Code؟ 1) What are Git, GitHub and VS Code?

عندما تسمع مصطلحات مثل Source Control أو Version Control أو النسخ الاحتياطي للكود — مهما كان الاسم، فالمقصود هو شيء واحد: تتبّع الكود والملفات طوال الوقت حتى تعرف مَن غيّر ماذا ومتى، وتقدر ترجع لأي نسخة سابقة. إليك الفرق بين البرامج الثلاثة:

When you hear terms like Source Control, Version Control, or code backup — whatever you call it, it means one thing: tracking your code and files over time, so you know who changed what and when, and you can return to any previous version. Here is how the three tools differ:

البرنامجTool ما هو؟What is it?
Git برنامج لإدارة الـ Source Code على جهازك (تتبّع التغييرات محلياً) A tool that manages your source code on your machine (tracks changes locally)
GitHub موقع يستضيف نسخة من كودك في repository على الإنترنت A website that hosts a copy of your code in an online repository
VS Code محرّر الشفرة الذي يجعل استخدام Git و GitHub سهلاً وبأزرار The code editor that makes using Git & GitHub easy with buttons

2) هل Git مثبّت على جهازك؟ 2) Is Git installed on your machine?

  1. افتح Terminal (على ماك) أو Command Prompt أو Git Bash (على ويندوز)
  2. Open Terminal (macOS) or Command Prompt / Git Bash (Windows)
  3. اكتب الأمر: git version واضغط Enter
  4. Type the command: git version and press Enter

إذا ظهر رقم الإصدار فـ Git موجود ✅، وإذا ظهرت رسالة "أمر غير معروف" فحمّله من git-scm.com/downloads واتبع دليل التثبيت الرسمي.

If a version number appears, Git is installed ✅. If you see “command not found”, download it from git-scm.com/downloads and follow the official install guide.

3) أول خطوة في VS Code: تهيئة مجلد (Initialize) 3) First step in VS Code: initialize a folder

لكي نربط مشروعنا بنظام التتبّع، نفتح المجلد في VS Code ثم:

To connect your project to version control, open the folder in VS Code and then:

  1. افتح مجلد مشروعك: File ▸ Open Folder
  2. Open your project folder: File ▸ Open Folder
  3. اضغط أيقونة Source Control في الشريط الجانبي الأيسر
  4. Click the Source Control icon in the left sidebar
  5. اضغط Initialize Repository — وبهذا يبدأ Git بتتبّع ملفاتك
  6. Click Initialize Repository — Git now tracks your files

💡 ستظهر ملفاتك في قائمة التغييرات. اكتب رسالة (Commit Message) تصف تعديلك ثم اضغط Commit، وعندما تجهز انشر مشروعك بزر Publish Branch إلى GitHub.

💡 Your files will appear in the Changes list. Write a Commit Message describing your edit, click Commit, and when you are ready publish your project to GitHub with Publish Branch.

# grade_calculator.py — exactly the same idea
def calculate_average(grades):
    return sum(grades) / len(grades)

def determine_letter_grade(average):
    if average >= 90: return 'A'
    elif average >= 80: return 'B'
    elif average >= 70: return 'C'
    elif average >= 60: return 'D'
    else: return 'Fail'

💡 Learn to translate ideas between languages: Python's sum maps to reduce or a loop in JavaScript, and if/elif maps to if/else if.
